⚙️ TNSDC IBM Agentic AI Use Case 1 - System Architecture

Detailed technical breakdown demonstrating RAG, Tool Calling, and Memory implementation for evaluators.

1. RAG Vector Search

- Vector Engine: TF-IDF similarity & cosine scoring.
- Indexed Documents: 8 pre-loaded regulations, syllabus, FAQs + User drag-drop upload.
- Citation Generation: Extracts confidence scores and direct text snippets.

2. Executable Tools Calling

- Tool Registry: 5 functions (Exam Timetable, CGPA Calculator, Faculty Finder, Fee Dues, Library Catalog).
- UI Widget Stream: Embedded HTML widget cards dynamically rendered inside the conversation stream.

3. Memory System

- Student Profile Store: Name, Roll No, Department, CGPA, Scholarship Quota.
- Short-term Buffer: Sliding window conversation history.
- Long-term Facts: Auto-extracted user facts persisted in LocalStorage.
